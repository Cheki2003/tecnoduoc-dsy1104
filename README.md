# TecnoDUOC - Proyecto de e-commerce

Este proyecto es una tienda web estática de tecnología y electrónica, desarrollada con HTML, CSS, Bootstrap 5 y JavaScript.

## Descripción
La aplicación incluye:
- página principal con carrusel promocional
- catálogo de productos
- carrito de compras
- inicio de sesión y sesión de usuario
- panel administrativo
- diseño responsivo

## Estructura principal
- `index.html` — página principal
- `productos.html` — catálogo de productos
- `carrito.html` — carrito de compras
- `login.html` — acceso de usuarios
- `admin.html` — panel administrador
- `css/styles.css` — estilos personalizados
- `js/` — lógica de la aplicación
- `docs/guia-ejecucion.md` — guía de ejecución

## Cómo levantar el proyecto
### Opción 1: usando Python
Abre una terminal dentro de la carpeta del proyecto y ejecuta:

```powershell
python -m http.server 8000
```

Luego abre en el navegador:

```text
http://localhost:8000
```

### Opción 2: usando Live Server en VS Code
1. Abre la carpeta en Visual Studio Code.
2. Abre `index.html`.
3. Haz clic derecho y selecciona `Open with Live Server`.

## Importante
No cambies la estructura de carpetas ni los nombres de los archivos principales si quieres que los enlaces funcionen correctamente.
